Backend — Public Endpoints

  • GET /health - Backend health check
  • GET /health/db - Database connection check
  • POST /api/auth/login - Authenticate user
  • POST /api/auth/register - Register new user
  • GET /api/albums/featured - Featured albums
  • GET /api/artists/featured - Featured artists
  • GET /api/albums/recent - Recent releases
  • GET /api/artists/{id} - Artist details
  • GET /api/artists/search - Search artists by name
  • GET /api/albums/{id} - Album details
  • GET /api/songs/{id} - Song details
  • GET /api/albums/search?q={query} - Search albums by title
  • POST /api/requests/{id}/respond - Respond to request (admin)

Backend — Authenticated Endpoints 🔒

  • GET /users - List all users
  • POST /users - Create user
  • GET /users/{id} - Get user by ID
  • PUT /users/{id} - Update user
  • DELETE /users/{id} - Delete user
  • PUT /users/{id}/favorite-artist - Set favorite artist
  • DELETE /users/{id}/favorite-artist - Remove favorite artist
  • GET /api/collections - List user's collection
  • POST /api/collections - Add album version to collection
  • DELETE /api/collections/{id} - Remove from collection
  • GET /api/requests - List version requests
  • POST /api/requests - Submit version request
  • GET /api/notifications - List notifications
  • GET /api/notifications/unread-count - Count unread notifications
  • POST /api/notifications/mark-all-read - Mark all notifications as read
  • POST /api/notifications/{id}/read - Mark single notification as read
  • GET /api/lists - List user's custom lists
  • POST /api/lists - Create a custom list
  • DELETE /api/lists/{id} - Delete a custom list
  • GET /api/lists/{id}/items - View list contents
  • POST /api/lists/{id}/items - Add album to list
  • DELETE /api/lists/{id}/items/{albumId} - Remove album from list

Frontend — Public Routes

  • / - Home page (hero + featured albums/artists/releases)

  • /login - Login form
  • /register - Registration form
  • /artists/{id} - Artist details
  • /artists/{id}/albums - Artist albums
  • /albums/{id} - Album details
  • /songs/{id} - Song details
